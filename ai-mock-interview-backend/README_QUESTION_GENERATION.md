# Question Generation System Documentation

## Overview

This system converts LeetCode problem links into completely original, legally-safe coding questions using AI-powered pattern analysis and generation. All questions are pre-generated and validated for uniqueness.

## System Architecture

```
ai-mock-interview-backend/
├── data/
│   ├── pattern_library.json          # Algorithmic patterns extracted from LeetCode
│   ├── original_questions.json       # Generated original questions
│   └── validation_report.json        # Uniqueness validation results
├── scripts/
│   └── validate_uniqueness.py        # Validation script using TF-IDF similarity
└── app/
    ├── question_service.py            # Question service with in-memory caching
    ├── question_endpoints.py          # API endpoint templates
    └── main.py                        # FastAPI application (add endpoints here)
```

## API Endpoints

### 1. Get Statistics
```http
GET /api/v1/questions/stats
```

Returns question database statistics including counts by difficulty, company, and topic.

**Response:**
```json
{
  "total_questions": 5,
  "by_difficulty": {"Easy": 3, "Medium": 2},
  "by_company": {"JP Morgan": 5, "Capgemini": 3, "Deloitte": 3},
  "companies": ["JP Morgan", "Capgemini", "Deloitte"],
  "difficulties": ["Easy", "Medium"],
  "topics": ["Array", "Hash Table", "Stack", "String", "Sliding Window"]
}
```

### 2. Get Random Question
```http
GET /api/v1/questions/random?company=JP%20Morgan&difficulty=Easy&topic=Array
```

Returns a random question matching the specified filters.

**Query Parameters:**
- `company` (optional): Filter by company
- `difficulty` (optional): Easy, Medium, or Hard
- `topic` (optional): Filter by algorithmic topic

### 3. Get Question by ID
```http
GET /api/v1/questions/q001_trading_pair_target
```

Returns a specific question by its unique ID.

### 4. Get Questions by Company
```http
GET /api/v1/questions/company/JP%20Morgan
```

Returns all questions for a specific company.

### 5. Get Questions by Difficulty
```http
GET /api/v1/questions/difficulty/Easy
```

Returns all questions at a specific difficulty level.

### 6. Get Questions by Topic
```http
GET /api/v1/questions/topic/Array
```

Returns all questions covering a specific topic.

### 7. Search Questions
```http
GET /api/v1/questions/search?q=trading&limit=10
```

Search questions by title or description.

## Validation Process

The validation script (`validate_uniqueness.py`) ensures:

1. **TF-IDF Similarity < 0.7** - Questions are sufficiently different from originals
2. **No Exact Phrase Matches** - No 10+ word sequences match LeetCode content
3. **Title Uniqueness** - Titles are completely different
4. **No LeetCode-Specific Phrases** - No references to "LeetCode", "Example 1:", etc.

## Adding More Questions

To add more questions:

1. Create new question objects following the schema above
2. Add them to the `questions` array in `data/original_questions.json`
3. Run validation: `python scripts/validate_uniqueness.py`
4. Restart the server to load new questions

## Troubleshooting

### Question Service Not Loading

**Error**: `ModuleNotFoundError: No module named 'question_service'`

**Solution**: Ensure `app/question_service.py` exists and the import path is correct.

### Validation Fails

**Error**: Questions fail uniqueness validation

**Solution**: Review the validation report in `data/validation_report.json` and regenerate flagged questions with different contexts.

### API Returns 404

**Error**: `No questions found matching filters`

**Solution**: Check that your filters match existing question attributes. Use `/api/v1/questions/stats` to see available companies, difficulties, and topics.
